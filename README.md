# An Efficient High-Precision Surrogate Model for Calculating the Failure Probability of Gas Pipelines

This project presents a novel approach to pipeline failure probability assessment using advanced deep learning techniques. Our model leverages the Transformer architecture to process and analyze massive time-series datasets, training on **35,784,000** data points to develop a high-precision surrogate model for pipeline reliability analysis.

---
The model demonstrates exceptional performance on unseen data, achieving **92%** relative accuracy for burst probability and **91%** accuracy for leakage detection on a test set of **768,000** samples. This represents a significant advancement in predictive maintenance for critical infrastructure.

---
The complete solution has been integrated into a user-friendly web interface available at [https://laili-civil.github.io/pipeline_BL/](https://laili-civil.github.io/pipeline_BL/). Users can directly input pipeline parameters to calculate failure probabilities without requiring local model deployment or specialized technical knowledge.

---
This work contributes to the field of structural reliability by providing an efficient, accurate, and accessible solution for gas pipeline failure probability calculation, ultimately supporting safer infrastructure management and maintenance decisions.
