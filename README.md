An Efficient High-Precision Surrogate Model for Calculating the Failure Probability of Gas Pipelines<br>
<br>
This project presents a novel approach to pipeline failure probability assessment using advanced deep learning techniques. Our model leverages the Transformer architecture to process and analyze massive time-series datasets, training on **35,784,000** data points to develop a high-precision surrogate model for pipeline reliability analysis.<br>
<br>
The model demonstrates exceptional performance on our test set of **768,000** samples, achieving remarkable results:<br>
- Burst probability prediction: **92%** relative accuracy<br>
- Leakage detection: **91%** accuracy<br>
<br>
The entire system is integrated into a user-friendly web interface at [https://laili-civil.github.io/pipelineBL/](https://laili-civil.github.io/pipelineBL/), where users can directly input pipeline parameters to obtain real-time probability calculations for potential failure modes. This tool enables engineers and safety professionals to quickly assess pipeline risks without requiring extensive computational resources.<br>
<br>
Our work contributes to the field of structural reliability by providing an efficient, accurate, and accessible solution for gas pipeline failure probability calculation, ultimately supporting safer infrastructure management and maintenance decisions.
